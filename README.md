# Sourav Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` - main page
- `css/style.css` - full styling and responsive layout
- `js/script.js` - mobile navigation and active section behavior
- `images/` - add your profile/project images here

## Add your real profile photo

Replace the `profile-placeholder` inside `index.html` with:

```html
<img src="images/profile.jpg" alt="Sourav">
```

and add your image as `images/profile.jpg`.

## GitHub Pages

Push the whole folder to a GitHub repository. If using the GitHub Pages Actions workflow, keep the workflow file in `.github/workflows/`.
